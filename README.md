# 🌐 Universal Media Downloader Telegram Bot

Ushbu Telegram bot barcha asosiy ijtimoiy tarmoqlardan video va rasmlarni asl sifatda yuklab beradi, TikTok videolarini **suv belgisiz (watermark-free)** oladi hamda har qanday videodan **MP3 audio** ajratib beradi!

---

## 🌟 Qo'llab-quvvatlanadigan Platformalar

1. 📸 **Instagram:** Post, Stories, Reels va fotosuratlar (albom/karusel bilan).
2. 🔴 **YouTube:** Video, Shorts va MP3 audio.
3. 🎵 **Tik Tok:** Suv belgisiz (no watermark) toza video va foto slaydlari.
4. 🔵 **Facebook:** Reels, fotosuratlar va videolar.
5. 📌 **Pinterest:** Rasm (original sifat) va videolar.
6. 👻 **Snapchat:** Spotlight, hikoya va videolar.
7. ✈️ **Telegram:** Ommaviy kanallardagi hikoyalar (stories) va postlar.

---

## 🛠 Asosiy Qulayliklar

- **🎵 Audio (MP3) ajratish:** Har qanday video ostidagi tugma orqali soniyalar ichida yuqori sifatli (192kbps) MP3 audio olish.
- **📥 720p (HD) / 1080p (Full HD):** Videoni o'zingizga qulay o'lchamga o'tkazib yuklash.
- **🖼 Albom / Karusel qo'llab-quvvatlash:** Bir nechta rasm yoki videoli postlar Telegram'da tartibli albom tarzida taqdim etiladi.
- **🚀 24/7 Avtomatik ishlash:** Railway / Docker hamda Windows avto-qayta ishga tushirish skriptlari mavjud.

---

## 🚀 Ishga tushirish

```bash
# 1. Kutubxonalarni o'rnatish
pip install -r requirements.txt

# 2. Botni ishga tushirish
python -u main.py
```
